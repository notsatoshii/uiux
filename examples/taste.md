# taste.md (example)

Copy this file to your project root as `taste.md`. The critics and the builder load it first, before the skill's own taste. Write it in your own words; examples beat adjectives.

## Likes
- Real materials: 3D clay rendered with light and shadow, opaque frosted glass. Not CSS or SVG imitations of clay.
- Big, few objects in a composition, partly behind the glass, like the test board we picked.
- Jua for display, Pretendard for text, Korean written to be read aloud.
- Numbers shown as ranges with a source, never as promises.

## Dislikes
- Small stickers scattered as decoration.
- Grey shadows; gradients on text; purple-blue anything.
- Pages that look like a SaaS template with our logo on it.
- Copy that reads as translated from English.

## Closest references
- Toss for phone-first clarity and plain language.
- Linear for restraint in the app.
- Family for motion that explains.
