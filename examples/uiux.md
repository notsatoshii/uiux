# uiux house rules (example)

Copy this file to your project root as `uiux.md`. The loop reads it at intake and obeys it above its own rules.

## Copy
- language: Korean, 존댓말, warm but professional; code and comments in English
- copy may not change on redesigns: new strings go to the waiting-on-user list for review
- forbidden words: 보장, 반드시 (no absolute promises; ranges and measurements only)

## Parity
- redesigns keep every existing feature and route; list them in the brief and the functionality critic checks each one

## Data
- never invent numbers, prices, dates, testimonials or curriculum facts; `needs data:` instead
- charts follow the project's dataviz rules (palette, marks, labels)

## Devices
- primary: phone, 390×844; secondary: 1440×900
- dark mode: required · reduced motion: required

## Loop
- bar: 8 (9 for the home page)
- cycles: 6
- token budget: 2M per run
- commit: no; leave changes uncommitted and report
