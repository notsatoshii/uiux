# References, by mode

Products and pages whose craft has held up. One line each on why. Look at them for the bar and the mechanics; never for a layout to lift. If one is gone or redesigned since, the reason listed is still the point.

## Persuade (landing, pricing, marketing)

| Reference | Why it is good |
|---|---|
| [Linear](https://linear.app) | Restraint as identity: one typeface, one accent, dark that is not black, copy that states instead of hypes; every section earns its place. |
| [Stripe](https://stripe.com) | Density without clutter; proof shown (real code, real dashboards); gradients used once, with intent; the best pricing mechanics on the web. |
| [Vercel](https://vercel.com) | Black and white done with discipline; type scale does the hierarchy; motion is fast and explanatory. |
| [Toss](https://toss.im) | The Korean standard: plain language for a hard topic, generous type for phones, one action per screen, illustrations with a consistent world. |
| [Family](https://family.co) | Motion as the signature move: every transition explains a spatial model; the hero is an interaction, not a screenshot. |
| [Resend](https://resend.com) | A developer product that still feels designed; a single strong visual idea carried through. |
| [Raycast](https://www.raycast.com) | Product shown doing its job in the hero; dark UI with real depth; feature pages that read as one system. |
| [Apple](https://www.apple.com) | Pacing: loud hero, quiet reading, loud again; scroll-driven reveals that are tied to the product's physical form; typography that never shouts twice. |
| [Cal.com](https://cal.com) | Open, calm, sans-only; shows the scheduling mechanic in the first viewport instead of describing it. |
| [PostHog](https://posthog.com) | Proof that loud can be good: a strong illustration world, humour in the copy, and still readable and fast. Use as the "bold" bar. |

## Operate (apps, dashboards, admin, tools)

| Reference | Why it is good |
|---|---|
| [Linear (the app)](https://linear.app) | Keyboard-first; every state designed; density tuned for daily use; nothing decorative. |
| [Toss (the app)](https://toss.im) | Finance for everyone on a phone: huge tap targets, one number per screen when it matters, errors in plain words. |
| [Notion](https://www.notion.so) | Content first, chrome second; hover reveals controls; empty states that teach. |
| [Figma](https://www.figma.com) | Tools that disappear while you work; panels with consistent rhythm; the canvas leads. |
| [Arc](https://arc.net) | A browser that feels like one object: colour as workspace identity, sidebar as the one navigation. |
| [Things](https://culturedcode.com/things/) | Twenty years of removing; spacing and type that make a list feel calm. |
| [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) | The reference for native expectations: hit targets, hierarchy, motion that respects the platform. |

## Read (docs, articles, guides)

| Reference | Why it is good |
|---|---|
| [Stripe Docs](https://docs.stripe.com) | Three columns that never fight; code and prose in rhythm; the search is the navigation. |
| [Josh Comeau](https://www.joshwcomeau.com) | Teaching through interaction; the playful bits serve comprehension; a personal voice that stays precise. |
| [Butterick's Practical Typography](https://practicaltypography.com) | The reading experience is the argument; measure, leading and size that you forget you are reading. |
| [Rauno Freiberg](https://rauno.me) | Craft notes on interaction; the site itself is a demonstration of restraint and detail. |
| [Emil Kowalski](https://emilkowal.ski) | Motion explained by someone who ships it; the writing on easing and duration is the standard. |
